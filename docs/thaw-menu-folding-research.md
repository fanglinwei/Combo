# Thaw 菜单栏折叠实现核查（2026-09-23）

**结论：Thaw 值得作为 Combo 的首选实现参照，但公开源码不能证明其 macOS 27 发行版使用同一机制。** 本文核对的是 Thaw 公开 `development` 分支提交 [`46a306a9`](https://github.com/thaw-app/Thaw/tree/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4)。Thaw 的[构建 action](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/.github/actions/checkout-source/action.yml#L1-L6)明确写明：`thaw-next` 是**私有的 macOS 27 代码库**；同一 action 将公开 Thaw 设为 26.0 部署目标、`thaw-next` 设为 27.0；[发布工作流](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/.github/workflows/release.yml#L24-L29)可选两个源码库。公开 [README](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/README.md)宣称支持 macOS 26/27，但仅凭公开源码不能断定 27.0（26A428）上 `10,000 pt` 分隔项、窗口枚举或合成拖拽可用；本次没有在该系统上运行 Thaw 或操作图标。

## 公开源码的实际链路

1. **建立可隐藏区域。** `ControlItem` 创建三个 `NSStatusItem` 分隔项（可见、隐藏、始终隐藏）；隐藏状态把后两个长度设成 `10,000 pt`，把位于它们左侧的项目推离屏幕，展开时恢复普通长度。它没有把各图标的系统可见性设为 false。[分隔项源码](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/ControlItem/ControlItem.swift#L14-L61)、[状态项长度与透明处理](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/ControlItem/ControlItem.swift#L606-L735)。
2. **发现并确认身份。** 私有 `CGSGetProcessMenuBarWindowList` 枚举状态项窗口 ID，`MenuBarItem.getMenuBarItemWindows` 取得几何位置；XPC `MenuBarItemService` 再把 CG 窗口与各 App 的 AX extras menu bar 子项按几何位置、标题等相关联，解决 macOS 由 Control Center 托管图标时，窗口 owner PID 不等于实际来源的问题。这条路不依赖先读出 Control Center 的 AX 菜单栏根项，因此与 Combo 先前遇到的根属性 `-25212` 是不同的入口。[私有符号](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Shared/Bridging/Shims.swift#L139-L149)、[窗口筛选](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Shared/Bridging/Bridging.swift#L495-L564)、[项目枚举](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItem%2BEnumeration.swift#L134-L162)、[PID/AX 关联](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/MenuBarItemService/SourcePIDCache.swift#L547-L650)。
3. **按项折叠。** 目标图标通过合成按住 Command 的鼠标拖拽，移动到分隔项左侧或右侧，系统保存其新位置；事件绑定窗口 ID，移动前重新取得端点、验证几何并限制超时。`MenuBarItemTag` 把 `Battery`、`Sound`、`WiFi` 识别为 Control Center 模块；但名称本身不是当前机器上的可操作证据，仍须唯一匹配实时窗口并验证拖动结果。[系统模块标题](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemTag.swift#L269-L290)、[移动与重新取端点](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemManager/MenuBarItemManager%2BMove.swift#L1134-L1235)、[Command 事件](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemManager/MenuBarItemEventTypes.swift#L25-L39)。钟表、控制中心入口、屏幕共享在 Thaw 中列为不可移动；音视频指示等列为不可隐藏。[限制清单](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemTag.swift#L420-L430)。
4. **从管理器打开原生菜单。** `temporarilyShow` 记录原分区及返回位置，把隐藏图标拖到可见分区，待位置稳定后对实时目标点击；部分项目用 AX press，其他用合成鼠标事件。随后按弹出窗口是否仍可见与用户输入状态，轮询并拖回原分区。返回失败会保留恢复记录，不继续假装已折叠。[临时放出/点击](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemManager/MenuBarItemManager%2BTemporaryShow.swift#L529-L815)、[点击策略](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemManager/MenuBarItemManager%2BClick.swift#L138-L229)、[重藏重试](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemManager/MenuBarItemManager%2BTemporaryShow.swift#L894-L1092)、[重启后的待恢复搬移](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/MenuBar/MenuBarItems/MenuBarItemManager/MenuBarItemManager%2BControlItemOrder.swift#L350-L550)。这不等于崩溃后无需重启即可自动恢复：图标物理顺序可能已被 macOS 持久化。

## 对 Combo 的判断

- **优先验证公开机制的最小垂直链路**：只读枚举窗口 → 三个系统项目各自唯一识别 → 任选一项拖入分区并核实离屏 → 临时放出并打开其原生菜单 → 菜单关闭后拖回；每一步失败，该项保持可见，其他项独立继续。不要仅因 `Battery`/`Sound`/`WiFi` 标题命中就动作。macOS 27 是否仍支持相关 CGS 私有符号和长分隔项必须在当前机器实测。既有私有白名单调研保留为备选方案。
- **权限**：公开 Thaw 将辅助功能列为发现、移动、点击的必需授权；屏幕录制仅用于实时预览、取色、视觉搜索，可缺省运行。核心窗口枚举使用 CGS，非截图；不要为 Combo 的折叠功能额外要求屏幕录制，除非实机验证出现具体缺口。[权限实现](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/Thaw/Permissions/Permission.swift#L140-L205)、[README 权限说明](https://github.com/thaw-app/Thaw/blob/46a306a9a2fcb0d7f808269230c6a5c4f7a586e4/README.md#L269-L296)。
