# Combo 产品行为与设置规格

整理：2026-10-09。面向开发维护者；描述当前行为，源码与实际系统读数为准。设备实现、历史技术证据和发布流程分别见 [工程文档](../README.md)、[后续研究](../research/roadmap.md) 与 [更新维护](../release/updates.md)。

## 1. 范围

Combo 面向 macOS 26+ 的 MacBook，将本机电量、网络路径、音量和媒体播放状态组合为一个菜单栏入口。外圈始终表示 Mac 本机电量；声音详情中的 AirPods 电量不改变外圈来源。无内置电池设备与关联设备电量来源仍见 [后续方向](../research/roadmap.md)。

## 2. 三个区域

| 区域 | 当前含义 |
| --- | --- |
| 外圈 | 本机电量；低电量红色，正在充电时绿色并显示闪电 |
| 中央 | 临时电源／音量事件、网络状态、优先电量或当前默认输出设备类型 |
| 底部 | 静音、音量圆点或固定播放音柱；未知音量显示占位 |

菜单栏、面板与设置预览共用状态选择和绘图规则。真实状态不可读取时明确显示未知，不伪造正常或成功。

## 3. 电量

外圈弧长随有效电量变化，接通电源与正在充电分开判断。新用户低电量数字显示阈值为 20%，已有 20%–80% 范围内的非零值保留，越界值调整到最近边界，0 保留关闭状态；关闭后保留上次正阈值。低电量红弧与中央数字显示条件分别处理。充电上限、能耗模式和高耗能应用的能力与限制见 [电池控制](../engineering/battery.md) 和 [高耗能应用研究](../engineering/battery.md#高耗能应用)。

## 4. 中央内容

中央优先级为 P4 电源／音量事件 → P3 Wi-Fi 连接中 → P2 异常、关闭、未知、电量与设备 → P1 普通 Wi-Fi。具体常驻选择、恢复和动画时序见 [中央状态优先级](#central-priority)。不提供日期或中央内容手动选择，设备切换不触发 P4 事件。

网络图形表示路径介质，不代表互联网连通性；面板内 Wi-Fi 信号另按 RSSI 展示。当前默认输出为蓝牙或 AirPlay 时使用共享分类结果，不以仅配对或仅连接代替当前输出身份。

## 5. 底部音量与播放

### 5.1 音量

底部四点表达音量，音量未知时显示短横线。连续调整从最后一次变化重新计算约 2 秒提示期，到期后重新判断媒体和静音状态。

### 5.2 固定播放动效

媒体播放时，四点伸长为四根圆角音柱，按预设相位约 1.2 秒循环。暂停或播放结束后回到音量圆点；动效关闭时显示音量状态，系统减少动态效果开启时使用静态高低音柱。动效只表达播放状态，不采集声音、不跟随音频节奏。

媒体状态来自系统注册的媒体客户端；未注册的播放器无法识别。通讯来源排除与兼容性边界见 [媒体实现证据](../engineering/media.md) 和 README，不将普通通知音当成已确认媒体播放。

### 5.3 显示优先级

| 优先级 | 条件 | 底部表现 |
| --- | --- | --- |
| 1 | 系统静音或音量为零 | 静音符号 |
| 2 | 调整音量提示尚未结束 | 音量圆点，未知值使用占位 |
| 3 | 媒体播放中且播放动效开启 | 循环音柱；减少动态效果时静态 |
| 4 | 其他情况 | 音量圆点，未知值显示短横线 |

中央网络状态与底部播放状态独立更新。提示结束后按最新状态恢复，不无条件重启音柱。

| 页面 | 当前实现 |

| 媒体来源 | 保留现有播放卡片与来源按钮；声音设置、四种图例、可展开读取说明 |

| 关于与帮助 | 真实品牌与应用版本、软件更新、能力与刷新、两种帮助入口及隐私说明 |

整个组合图标使用一个点击区域，打开电池、Wi-Fi、声音与媒体操作面板。

新用户低电量显示开启且阈值为 20%；阈值使用无刻度的小型滑块调整，完整轨道表示 0%–100%，滑块仅能在 20%–80% 区域移动，两端禁用区域为灰色，20% 和 80% 边界带竖向分隔线；按整数百分比保存，当前值在右侧显示并立即保存。旧阈值超出范围时调整到最近的边界，关闭值 0 保留。关闭后保存最后一次有效阈值，重启再开启仍恢复原值。

系统图标基线、当前检测结果与权限分开。按设备适用项目完整读取后才记录；已有完整基线不覆盖，恢复后也保留。恢复需用户确认具体记录值，部分失败只重试失败项。退出或下次启动均不会自动恢复，也不因旧恢复标记自动打开设置。窗口关闭结束演示，演示不持久化。指引使用已有 MenuBarBefore/After 图片，可不授权直接查看；需要权限时在指引内就地解释。

### 1. 窗口与导航

采用独立原生设置窗口，左侧为通用、外观与动效、菜单栏与控制、媒体来源、实验性项目、关于与帮助六页。窗口初始 850 × 690 pt，最小 780 × 620 pt，可调整，内容区可滚动；重复打开复用同一窗口，关闭窗口结束演示但不退出 Combo。普通偏好立即生效。

### 2. 通用

| 功能 | 控件与默认值 | 行为 |
| --- | --- | --- |
| 登录时启动 Combo | 开关，默认关闭 | 用户主动开启；显示系统实际注册状态及失败原因 |
| 恢复显示偏好 | 按钮，需确认 | 仅恢复播放动效开启、低电量显示开启且阈值为 20%；不改登录项、媒体来源、系统权限或图标布局 |
| 退出 Combo | 按钮 | 结束应用运行；不自动恢复系统图标 |

为避免“恢复默认”范围不清，按钮使用“恢复显示偏好”，确认文案列出具体两项。恢复系统图标另有专用按钮。

登录项使用 ServiceManagement 的 `SMAppService.mainApp` 注册/注销。界面根据真实 status 显示已开启、已关闭、需要系统批准或操作失败；应用重新激活时刷新，处理用户在系统设置中关闭登录项的情况。失败不只修改 UserDefaults 假装成功。不新增 daemon、管理员 helper 或循环自启动行为。

参考：[mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)、[register](https://developer.apple.com/documentation/servicemanagement/smappservice/register())。最终通过签名应用实测首次启用、拒绝、系统关闭及应用移动后的行为。

#### 3.1 中央状态优先级

设置预览与菜单栏使用同一套中央内容选择和动画规则；外圈电量、底部音量／播放仍独立更新。

Wi-Fi 正常使用两道圆头弧线与圆润倒三角；Wi-Fi 已关闭且没有可用网络路径时使用斜杠图标，属于 P2。有线网络可用时继续显示有线常驻内容。Wi-Fi 开启但无可用路径时显示 Wi-Fi 加感叹号，状态未知仍显示短横线。

| 等级 | 状态 | 结束条件 |
| --- | --- | --- |
| P4，最高 | 电源实际拔插 | 中央使用 C 方案线条插头：插入带圆形对勾，拔出带圆形 X，不显示电量数字；缩小完成后保持 5 秒，再恢复最新常驻状态；新事件覆盖旧事件，不补播 |
| P4 | 调整音量或切换静音，中央显示 0–100 纯数字，静音显示 0 | 不依赖媒体播放；短淡变，最后一次调整后 2 秒结束；连续调整续期，不重播入场；与电源提示互相覆盖，不补播 |
| P3 | Wi-Fi 正在连接 | 连接成功、失败或取消；被 P4 覆盖后仅在仍连接时恢复 |
| P2 | 网络异常／未知／关闭、优先电量、AirPods 耳机、兜底电量 | 按最新状态选择 |
| P1，最低 | Wi-Fi 正常 | 按最新状态选择 |

常驻选择顺序：网络异常／未知／关闭 → 已开启且低于用户阈值的电量数字 → 当前音频输出为蓝牙或 AirPlay 设备 → 充电且电量有效时的电量数字 → 正常 Wi-Fi → 电量百分比。电量恰好等于阈值时不触发低电量优先。暂停播放不移除当前设备符号；切回扬声器恢复其他常驻内容，仅蓝牙连接不触发耳机常驻。

系统静音或音量为零时底部显示静音；调整音量或静音触发的中央 P4 显示 0，取消静音显示恢复后的音量。P4 结束后按最新状态恢复：Wi-Fi 仍连接中则显示 P3，否则显示常驻内容。电量未知且无其他常驻内容时显示“—”。

一般同级不同状态和降级切换先使用中心短交叉淡变：普通模式约 0.23 秒，旧层缩到 0.7、新层从 0.7 恢复；减少动态效果时约 0.16 秒且不缩放。仅数字内容变化不重播入场。P4 事件互换、Wi-Fi 连接结束后的降级也先遵循此规则，不另承诺完整网络收尾动画。

升优先级时，满足网络变化／连接条件且两侧优先级均低于 P4，才进入网络专用时序；其余使用通用入场，音量目标或减少动态效果使用短淡变。电源完整入场在第 4.2 秒完成缩小，随后保持 5 秒，第 9.2 秒恢复常驻状态；这些时间不代表所有被打断或同级切换场景。音量提示总期按最后调整后 2 秒计算，底部提示同样按此恢复。电源事件只由供电来源变化触发，满电停充、手动上限暂停和恢复充电不触发插拔提示。

网络专用入场先放大中央（最多约 0.3 秒），再完成约 0.4 秒形变。连接中隐藏外圈和底部并持续亮度脉冲，不按固定时长结束；减少动态效果时不做空间缩放或亮度循环。连接结果、同级与降级按上面的中心过渡处理；被 P4 打断后按最新状态恢复，不补播旧事件。具体分支与帧参数以 [IconTransition.swift](../../Combo/Rendering/IconTransition.swift) 为准。

设备身份、分类、路由发现与权限生命周期见 [音频工程说明](../engineering/audio.md)。电源和默认输出设备事件来自系统；缺失设备符号退回 `headphones`。Wi-Fi 的连接过程来自 Combo 发起的连接操作，扫描不算连接；系统开关与链路事件会刷新关闭／异常图标。真实媒体检测使用隔离 helper 读取系统注册媒体客户端；示例场景仍不代表真实播放状态。

### 4. 菜单栏与控制

Wi‑Fi 卡片提供“使用系统保存的 Wi‑Fi 密码”开关（默认开启，以 `wifiUseSystemPasswords` 持久化）及可展开的“密码与隐私说明”入口。仅在用户点击已知的普通加密网络时按需请求对应密码；开关不表示系统已授权。拒绝或取消后停止本次连接，并在本次运行中暂停再请求，用户可在该入口点击“允许下次请求授权”。关闭开关会使尚未完成的读取结果失效，但不会撤销 macOS 已记录的项目访问权限。

隐私文案明确：仅为 Wi‑Fi 切换读取所选网络的密码，不读取其他钥匙串项目，不另存系统密码，不上传网络名称或密码。不授权时提供手动输入；“连接成功后在本机记住密码”默认勾选，用户可取消。保存位置是本机 Combo 钥匙串项目，失败连接不保存；已有 Combo 密码可在连接表单中删除。不要宣称“不读取任何数据”或全局“已授权”。

电量显示组提供“电池详情的高耗能应用”：菜单选择最多 1 / 2 / 3 个，默认 1，立即生效，以 `energyAppLimit` 持久化。数量是上限，不保证补足。主面板显示加载、正常空名单、应用列表或获取失败四种状态。接口与系统版本支持范围见 [系统高耗能应用研究](../engineering/battery.md#高耗能应用)。

主面板“个人热点”展示真实手机名称、四阶蜂窝信号条及电池轮廓内居中的电量整数（不带百分号，内部填充随电量变化）；未确认的网络制式隐藏。点击手机或右侧设置箭头打开系统 Wi-Fi 设置，由用户连接。空列表显示“未发现可用个人热点”，读取失败显示“暂时无法读取手机信息”及重试入口。打开面板时读取，关闭面板、屏幕休眠或 Wi-Fi 关闭时停止；目前私有发现能力仅支持已验证的 macOS build `26A428`。详见 [个人热点接入记录](../engineering/network.md#hotspot)。

#### 4.1 系统图标记录与手动恢复

用户在 macOS 菜单栏设置中手动隐藏图标。指引可直接查看，不以授权为前提；读取和记录需要辅助功能权限，记录前必须完整读取适用项目，已有完整基线不覆盖。恢复需确认记录值，失败项可单独重试。退出、重启和权限变化不会触发自动恢复，也不会自动启用折叠。

### 5. 媒体来源

这一页展示**现在在播什么、菜单栏会变成什么样、状态是怎么读到的**，并提供系统声音设置入口。

**当前在播。** 一条实时状态——正在播放／已暂停／重新连接中／未检测到播放——加封面、曲名、歌手与来源 App 的真实图标；系统能定位到该 App 时提供“打开”。空闲时说明原因：Combo 只显示向系统报告播放状态的应用。

**菜单栏会怎么变。** 四格对照，用 IconRenderer 渲染的四个真实状态：正在播放、已暂停、AirPods 播放、AirPods 已连接；当前状态那一格用强调色标题指认。“在菜单栏演示播放”留在这一节。被对照图换下去的两条规则（系统静音优先于播放、开启减少动态效果时不循环）保留为图例下一行说明。

**怎么读到的。** 读取：只读系统播放状态，不采集声音、不录音、不读网页内容。识别：未向系统报告播放状态的播放器不会出现在这里。保留：元数据暂时缺失时最多沿用最近约 5 秒的曲目信息；明确结束或不可见时可立即清除，切歌按身份更新。

### 6. 实验性项目与关于帮助

实验性项目保存目标预选，提供用户发起的只读菜单诊断；私有折叠实验继续暂停，预选或授权不代表已折叠。历史技术证据见 [macOS 菜单折叠研究](../research/roadmap.md#menu-bar)。

关于与帮助显示真实品牌、应用版本、能力与刷新入口，提供使用帮助、系统图标指引和隐私说明。品牌资源以 [当前品牌说明](../assets/brand/README.md) 为准。

### 7. 持久化与可访问性

普通偏好使用 UserDefaults，系统权限与登录项状态实时读取；用户意愿、系统检测结果与图标基线分开保存。恢复显示偏好只重置播放动效、低电量显示及其 20% 阈值，不修改登录项、权限、Wi-Fi 密码偏好或图标记录。演示不持久化，关闭设置窗口结束。

控件保留原生标签、键盘焦点与读屏描述，状态不只靠颜色表达。实时图标适应深浅菜单栏；读屏描述随语义状态更新，不按动画帧重复播报。系统减少透明度、增强对比度、减少动态效果各有对应降级；预览每帧变化不触发读屏播报。

### 8. 验收与验证边界

`./verify.sh` 覆盖构建、状态规则、Helper、图标和签名。设置回归包含默认值、旧值迁移、阈值跨重启、完整基线、不覆盖记录、单项恢复规划和窗口关闭结束演示；`Tests/RenderSettings.swift` 用于离屏渲染，不代表真实授权或完整可访问性验收。

以下事项仍需实机检查：

- 全键盘导航、VoiceOver，以及系统三项可访问性设置的完整切换。
- 登录项注册失败／待批准及系统外部更改后的刷新。
- 当前应用签名下的真实权限、图标记录／恢复、Wi-Fi 连接与输出设备切换。
- AirPlay 权限弹窗、拒绝／重试、睡眠唤醒及硬件覆盖。
- 面板与详情进出、双向悬停、高度调整及菜单栏高亮的体感；减少动态效果下停止缩放和循环、保留必要淡变。
- 多卡片玻璃采样与较旧硬件性能，必要时用 Instruments 测量。

### 9. 软件更新

设置 → 关于与帮助，在品牌与版本信息之后显示软件更新栏。使用 Sparkle 2.10.0 标准更新窗口处理下载、安装和重启。自动检查默认开启，周期为 24 小时，偏好由 Sparkle 持久保存；禁止自动下载安装和系统概况上传。Debug 不启动更新器，并在设置页说明开发版本已停用检查。

软件更新栏最后一行显示“上次检查时间”，按当前区域格式显示本地日期与时间。手动或自动成功获取更新结果后记录；请求失败保留原成功时间，错误提示位于按钮附近。从未成功检查时显示“尚未检查”。

后台发现可用版本时，在面板设置按钮显示小圆点，并在更新栏显示版本；不抢焦点、不弹系统通知，也不改变菜单栏电池、网络、音频图标语义。用户点击检查／查看更新后打开 Sparkle 标准界面；关闭设置窗口不取消下载，跳过或结束更新会话后清除提醒。
