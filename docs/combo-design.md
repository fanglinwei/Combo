# Combo 当前产品行为

整理：2026-10-04。本文保留当前实现的产品约定；设置控件、状态时序和验证边界见 [设置规格](combo-settings.md) 与 [README](../README.md)。早期的日期选择、浏览器扩展适配和自动折叠实施方案已移除。

## 1. 范围

Combo 面向 macOS 26+ 的 MacBook，将本机电量、网络路径、音量和媒体播放状态组合为一个菜单栏入口。外圈始终表示 Mac 本机电量；声音详情中的 AirPods 电量不改变外圈来源。无内置电池设备与关联设备电量来源仍见 [后续方向](combo-roadmap.md)。

## 2. 三个区域

| 区域 | 当前含义 |
| --- | --- |
| 外圈 | 本机电量；低电量红色，正在充电时绿色并显示闪电 |
| 中央 | 临时电源／音量事件、网络状态、优先电量或当前默认输出设备类型 |
| 底部 | 静音、音量圆点或固定播放音柱；未知音量显示占位 |

菜单栏、面板与设置预览共用状态选择和绘图规则。真实状态不可读取时明确显示未知，不伪造正常或成功。

## 3. 电量

外圈弧长随有效电量变化，接通电源与正在充电分开判断。新用户低电量数字显示阈值为 20%，已有有效设置保留；关闭后保留上次正阈值。低电量红弧与中央数字显示条件分别处理。充电上限、能耗模式和高耗能应用的能力与限制见 [电池控制](battery-controls.md) 和 [高耗能应用研究](battery-controls.md#高耗能应用)。

## 4. 中央内容

中央优先级为 P4 电源／音量事件 → P3 Wi-Fi 连接中 → P2 异常、关闭、未知、电量与设备 → P1 普通 Wi-Fi。具体常驻选择、恢复和动画时序见 [中央状态优先级](combo-settings.md#31-中央状态优先级2026-09-24)。不提供日期或中央内容手动选择，设备切换不触发 P4 事件。

网络图形表示路径介质，不代表互联网连通性；面板内 Wi-Fi 信号另按 RSSI 展示。当前默认输出为蓝牙或 AirPlay 时使用共享分类结果，不以仅配对或仅连接代替当前输出身份。

## 5. 底部音量与播放

### 5.1 音量

底部四点表达音量，音量未知时显示短横线。连续调整从最后一次变化重新计算约 2 秒提示期，到期后重新判断媒体和静音状态。

### 5.2 固定播放动效

媒体播放时，四点伸长为四根圆角音柱，按预设相位约 1.2 秒循环。暂停或播放结束后回到音量圆点；动效关闭时显示音量状态，系统减少动态效果开启时使用静态高低音柱。动效只表达播放状态，不采集声音、不跟随音频节奏。

媒体状态来自系统注册的媒体客户端；未注册的播放器无法识别。通讯来源排除与兼容性边界见 [媒体实现证据](media-implementation-evidence.md) 和 README，不将普通通知音当成已确认媒体播放。

### 5.3 显示优先级

| 优先级 | 条件 | 底部表现 |
| --- | --- | --- |
| 1 | 系统静音或音量为零 | 静音符号 |
| 2 | 调整音量提示尚未结束 | 音量圆点，未知值使用占位 |
| 3 | 媒体播放中且播放动效开启 | 循环音柱；减少动态效果时静态 |
| 4 | 其他情况 | 音量圆点，未知值显示短横线 |

中央网络状态与底部播放状态独立更新。提示结束后按最新状态恢复，不无条件重启音柱。

## 6. 交互、设置与权限

整个组合图标使用一个点击区域，打开电池、Wi-Fi、声音与媒体操作面板；设置使用独立窗口和六页导航。系统图标由用户在 macOS 设置中手动隐藏，Combo 提供记录、指引和确认恢复；退出及下次启动不会自动恢复。自动折叠继续暂停。

授权只在对应操作需要时请求。登录项注册、Wi-Fi 密码读取、蓝牙、本地网络与辅助功能状态均以系统实际结果为准；失败或取消不显示操作成功。

## 7. 视觉、可访问性与验收

实时图标适应深浅菜单栏，品牌资源见 [品牌说明](assets/brand/README.md)。读屏描述随语义状态更新，不按动画帧重复播报；减少动态效果时保留必要淡变并停止空间缩放和循环。状态通过文字与图形共同表达。

[图标状态示例](combo-current-states.md)用于说明组合方式，历史 GIF 不替代当前源码和实机验收。自动检查由 `./verify.sh` 执行；键盘、VoiceOver、系统可访问性设置、真实授权与设备切换的待验收事项见 [设置规格的验收清单](combo-settings.md#8-验收与验证边界)。
