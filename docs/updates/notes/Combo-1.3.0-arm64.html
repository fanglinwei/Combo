Combo 1.3.0

中文

新增功能

  • 电池详情新增最大容量信息，使用 macOS 电池健康报告中的估算值；无法读取时明确显示不可用。
  • 外观页提供 33 种菜单栏图标效果预览，按网络、音频设备、电量与供电、音量与播放分组，演示不改变系统状态。

改进与功能精简

  • 重做总览、电池、Wi-Fi、声音详情、设置和使用引导，采用统一的玻璃界面与新版应用图标；详情在同一面板内切换。
  • 设置收敛为通用、外观、关于三个页面；保留系统、浅色和深色外观，移除主题色及菜单栏折叠实验，系统图标改由图文指引手动管理。
  • Wi-Fi 专注网络信息展示；连接网络、个人热点及 Wi-Fi 开关统一交由 macOS 系统设置处理，移除应用内密码输入、存储及钥匙串连接流程。
  • 低电量优先显示改为可开关的固定 20% 阈值；高耗能应用列表固定最多显示 3 项。
  • 整理电池容量读取与面板依赖，日常自动验证默认在后台运行。

安装说明

支持 Apple Silicon（arm64），需要 macOS 26 或更高版本。本版本使用 ad-hoc 签名，未进行 Apple 公证。请按照 DMG 内的安装指南安装和首次启动；覆盖安装前先退出 Combo。支持 Sparkle 的旧版本可通过软件更新升级；1.0.0 需手动安装。

English

New features

  • Adds maximum battery capacity to battery details, using the estimate from the macOS battery health report and showing an unavailable state when it cannot be read.
  • Adds 33 menu bar icon previews grouped by network, audio device, battery and power, and volume and playback. Previews do not change system state.

Improvements and simplified controls

  • Redesigns the overview, battery, Wi-Fi and sound details, Settings, and onboarding with a consistent glass interface and a new app icon. Details now switch within the same panel.
  • Organizes Settings into General, Appearance, and About. Keeps system, light, and dark appearances; removes color themes and the experimental menu bar folding controls. Illustrated instructions guide manual management of system icons.
  • Focuses Wi-Fi on network information. Network connections, personal hotspots, and the Wi-Fi switch open macOS System Settings; removes in-app password entry, storage, and Keychain connection flows.
  • Uses a fixed 20% threshold with an on/off preference for low-battery priority, and limits the energy-intensive app list to three entries.
  • Encapsulates battery capacity reads and panel dependencies, with routine automated validation running in the background by default.

Installation

Supports Apple Silicon (arm64) and requires macOS 26 or later. This release is ad-hoc signed and is not notarized by Apple. Follow the installation guide included in the DMG for installation and first launch, and quit Combo before replacing an installation. Older versions with Sparkle can use Software Update; version 1.0.0 requires manual installation.
