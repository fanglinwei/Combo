Combo 1.2.0 · Build 102

中文

新增功能

  • 补全 macOS 应用菜单，加入关于、检查更新、服务、隐藏和显示等标准菜单项；打开设置时显示 Dock 图标，关闭设置后恢复菜单栏运行。

改进

  • 低电量显示阈值改为滑块，支持 20%–80% 的整数百分比并即时保存；已有超出范围的阈值会调整到最近边界，关闭状态保持不变。
  • AirPods 电量行在面板展开后出现，并随电量数据更新；出现和消失时使用淡入淡出，遵循“减少动态效果”。

修复

  • 调整菜单栏常驻图标优先级：低电量数字优先于输出设备，输出设备优先于充电电量；暂停播放时保留当前设备图标。
  • 电量恰好等于设置阈值时不再触发低电量优先显示。
  • 重新打开设置时恢复已最小化的窗口。

安装说明

支持 Apple Silicon（arm64），需要 macOS 26 或更高版本。本版本使用 ad-hoc 签名，未进行 Apple 公证。请按 DMG 内的安装指南安装和首次启动。1.1.0 用户可通过软件更新入口升级；1.0.0 用户需手动安装。

English

New features

  • Completes the macOS application menu with About, Check for Updates, Services, Hide, and Show commands. Opening Settings shows the Dock icon; closing Settings returns Combo to menu bar operation.

Improvements

  • Replaces the low-battery threshold field with a slider supporting whole percentages from 20% to 80%, saved immediately. Existing out-of-range thresholds move to the nearest boundary; disabled preferences remain disabled.
  • Shows the AirPods battery row after the panel expands and refreshes it as battery data changes. The row fades in and out, respecting Reduce Motion.

Fixes

  • Adjusts persistent menu bar icon priority: low-battery numbers precede the output-device icon, which precedes charging percentages. The current device icon remains visible when playback is paused.
  • No longer prioritizes low-battery numbers when the battery level equals the configured threshold.
  • Restores a minimized Settings window when reopening it.

Installation

Supports Apple Silicon (arm64) and requires macOS 26 or later. This release is ad-hoc signed and is not notarized by Apple. Follow the installation guide included in the DMG for installation and first launch. Version 1.1.0 users can upgrade through Software Update; version 1.0.0 users must install manually.
