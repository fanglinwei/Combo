English

Fixes

  • Fixes an issue where the General, Appearance, and About icons and labels could disappear when opening Settings.

Installation

Supports Apple Silicon (arm64) and requires macOS 26 or later. This release is ad-hoc signed and is not notarized by Apple. Follow the installation guide included in the DMG for installation and first launch, and quit Combo before replacing an installation.
