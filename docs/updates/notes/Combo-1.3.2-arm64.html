Combo 1.3.2 · Build 105

中文

新增功能

  • 支持的蓝牙音频设备在总览和声音详情中显示电量圆环，区分整机、左右耳及充电盒；悬停查看数字，点击切换数字显示，未知或过期数据明确显示未知。
  • 扩展 AirPods、Beats、通用耳机、音箱及 AirPlay 设备图标，菜单栏、电量圆环与输出列表共用设备分类；外观页的效果预览扩展至 51 种。
  • 切换默认音频输出时，菜单栏短暂显示新设备图标。

改进

  • 改善中央图标切换的连续性，以及网络连接状态与临时提示之间的过渡，遵循“减少动态效果”。
  • 调整玻璃面板、设置背景、总览悬浮区域内边距和媒体来源按钮反馈。
  • 整理中英文 README，统一界面、AppIcon、中央图标和音频设计资料入口，明确浏览器快照与原生实现的区别。

安装与设备范围

支持 Apple Silicon（arm64），需要 macOS 26 或更高版本。本版本使用 ad-hoc 签名，未进行 Apple 公证。请按 DMG 内的安装指南安装和首次启动；覆盖安装前退出 Combo。支持 Sparkle 的旧版本可通过软件更新升级，1.0.0 需手动安装。

电量和设备识别取决于硬件、权限及系统返回的数据；图标目录不等于所有型号均经过实机验证。当前未采集可靠充电或入仓信号，不推测充电闪电、充满或双耳合并状态。

English

New features

  • Adds battery rings for supported Bluetooth audio devices in the overview and sound details, distinguishing the device, left and right earbuds, and charging case. Hover to read a number or click to toggle numbers; unknown or stale readings show an unknown state.
  • Expands AirPods, Beats, generic headphone, speaker, and AirPlay symbols, sharing device classification across the menu bar, battery rings, and output list. Appearance now includes 51 icon previews.
  • Briefly shows the new device symbol in the menu bar when the default audio output changes.

Improvements

  • Improves continuity when central symbols change and when network connection states transition to or from temporary hints, respecting Reduce Motion.
  • Refines glass panels, Settings backgrounds, padding within overview hover areas, and feedback on the media source button.
  • Updates both README languages and consolidates interface, AppIcon, central-symbol, and audio design references, distinguishing browser snapshots from native behavior.

Installation and device support

Supports Apple Silicon (arm64) and requires macOS 26 or later. This release is ad-hoc signed and is not notarized by Apple. Follow the installation guide included in the DMG for installation and first launch; quit Combo before replacing an installation. Older versions with Sparkle can use Software Update; version 1.0.0 requires manual installation.

Battery readings and device identification depend on hardware, permissions, and system data. The symbol catalog does not mean every model has been tested on hardware. Reliable charging and in-case signals are not currently collected, so charging bolts, full-charge states, and merged earbud states are not inferred.
