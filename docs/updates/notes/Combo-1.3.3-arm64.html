中文

修复

  • 重新查找附近 AirPlay 设备时保留现有列表，避免刷新期间列表消失和面板闪动。
  • 修复内容快速变化时旧的缩放动画覆盖最新面板高度，导致内容显示不完整的问题。

改进

  • 调整网页设计预览的布局与图标尺寸，整理文档索引和重复的测试迁移记录。

安装说明

支持 Apple Silicon（arm64），需要 macOS 26 或更高版本。本版本使用 ad-hoc 签名，未进行 Apple 公证。请按 DMG 内的安装指南安装和首次启动；覆盖安装前退出 Combo。支持 Sparkle 的旧版本可通过软件更新升级。

English

Fixes

  • Keeps the existing list visible while refreshing nearby AirPlay devices, preventing the list from disappearing and the panel from flickering during refresh.
  • Fixes an issue where an earlier resize animation could override the latest panel height after rapid content changes, leaving content clipped.

Improvements

  • Refines the layout and icon sizes in web design previews, and consolidates documentation indexes and completed test migration records.

Installation

Supports Apple Silicon (arm64) and requires macOS 26 or later. This release is ad-hoc signed and is not notarized by Apple. Follow the installation guide included in the DMG for installation and first launch; quit Combo before replacing an installation. Older versions with Sparkle can use Software Update.
