Combo 1.1.0

中文

新增功能

在“设置 → 关于与帮助”加入软件更新入口，支持手动检查更新。

自动检查更新默认开启，每 24 小时在后台检查；用户关闭后保留偏好。

软件更新栏底部显示上次成功检查时间，检查失败时保留原时间。

有新版本时在面板设置入口显示轻量提示；下载和安装通过 Sparkle 标准更新窗口确认。

安装说明

支持 Apple Silicon（arm64），需要 macOS 26 或更高版本。本版本使用 ad-hoc 签名，未进行 Apple 公证。请按 DMG 内的安装指南安装和首次启动。

1.0.0 没有自动更新框架，需要手动安装一次 1.1.0；后续支持通过更新入口升级。

English

New features

Adds manual update checking under Settings → About & Help.

Enables automatic checks by default, checking in the background every 24 hours while preserving a user's opt-out.

Shows the last successful check time at the bottom of the software update card; failed checks retain the previous time.

Adds a subtle update indicator to the panel's settings button. Downloads and installation use Sparkle's standard confirmation window.

Installation

Supports Apple Silicon (arm64) and requires macOS 26 or later. This release is ad-hoc signed and is not notarized by Apple. Follow the installation guide included in the DMG for installation and first launch.

Version 1.0.0 has no automatic updater. Install 1.1.0 manually once to enable updates for later releases.
